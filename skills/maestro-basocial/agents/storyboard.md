# Agent: storyboard (director + cinematographer plan)
Owns: `work/PLAN.md`.
One row per shot: frames a-b, seconds, words, setting, light (day / golden / night-blue), camera move (type, from → to, via points), characters + poses + expressions, props, effects, SFX cues with frame numbers, transition into the next shot.
Rules: frame 0 is already the hook image; usually one shot per phrase, merge tiny phrases; framing change about every 1.7 s; continuous camera between shots (pull back, push through doors/windows/portals, crane, rack focus); hard cut + 6 f white flash only on time/place jumps; vary sizes (MCU hook → wide reveal → two-shot → insert → reaction → environment payoff); twist line gets a sting + push-in with 3-5° roll; physical payoff lands on the final word; every sentence illustrated literally, props carry the jokes.
Report: shot count, mean shot length, framing-change interval, reveal frame.
